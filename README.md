# New Year Automation (Python)

This project is a simple Python automation that displays a New Year greeting message automatically every **January 1st at 00:00** using **GitHub Actions**.

## Features
- Python-based automation
- Runs automatically every year
- Uses GitHub Actions (CI/CD)
- Clean and beginner-friendly code

## Output
Happy New Year 2026
All my best wishes

## How it works
- A Python script generates the message
- GitHub Actions runs the script every January 1st at midnight (UTC)

## Technologies
- Python 3
- GitHub Actions
- YAML (CI/CD)

## Manual run
You can also run it manually from GitHub Actions using `workflow_dispatch`.
